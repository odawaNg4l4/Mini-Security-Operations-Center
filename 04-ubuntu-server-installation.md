# Ubuntu Server Installation

## Project Overview

Ubuntu Server was selected as the operating system to host the Wazuh Security Information and Event Management (SIEM) platform. The server acts as the central management node responsible for collecting, processing, analysing, and storing security events generated by monitored endpoints.

This installation forms the backbone of the SOC lab and provides the infrastructure required for endpoint enrolment, log analysis, detection engineering, and incident response.

---

# Objectives

The objectives of this phase were to:

- Install Ubuntu Server in Oracle VirtualBox.
- Configure basic system settings.
- Enable remote administration using OpenSSH.
- Verify hardware resources.
- Update the operating system.
- Prepare the server for Wazuh installation.

# Installation Process

## 1. Download Ubuntu Server

The Ubuntu Server ISO was downloaded from the official Ubuntu website.

Before installation, the SHA256 checksum was verified to ensure the ISO had not been corrupted or modified during download.

Verifying checksums is an important security practice because it confirms the integrity and authenticity of installation media.

---

## 2. Create the Virtual Machine

A new virtual machine was created in Oracle VirtualBox using the following specifications.

| Resource | Allocation |
|----------|------------|
| CPUs | 2 vCPUs |
| Memory | 4 GB RAM |
| Storage | 50 GB Virtual Disk |
| Network | Internal Network |

---

## 3. Install Ubuntu Server

The Ubuntu Server installation wizard was used to configure:

- Language
- Keyboard layout
- Time zone
- Storage configuration
- Hostname
- Username
- Password

The default partitioning scheme was selected for this lab.

---

## 4. Enable OpenSSH

During installation, the **OpenSSH Server** package was selected.

This allows remote administration of the server using SSH without requiring direct interaction through the VirtualBox console.

Remote administration becomes especially important when managing production Linux servers and security appliances.

---

## 5. Complete Installation

After the installation completed:

- The virtual machine rebooted successfully.
- The installation media was removed.
- Ubuntu booted into the newly installed operating system.

# Post-Installation Configuration

After logging into Ubuntu, the operating system was updated.

```bash
sudo apt update
sudo apt upgrade -y
```

### Command Explanation

#### `sudo`

Executes the command with administrative (root) privileges.

---

#### `apt update`

Downloads the latest package information from Ubuntu repositories.

This command updates the package index but **does not install any software**.

---

#### `apt upgrade -y`

Installs the latest available updates for installed packages.

The `-y` option automatically answers "Yes" to confirmation prompts.

Keeping the operating system updated reduces known vulnerabilities before deploying security software.

---

```

Displays disk usage for mounted file systems.

---

```

Displays processor information including CPU architecture and allocated virtual CPUs.
